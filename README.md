# Cryptbound

A mobile-first, top-down dungeon action prototype inspired by classic arcade dungeon games.

## Play

Once GitHub Pages is enabled for the `main` branch and repository root, the game will be available at:

`https://alterx3509.github.io/cryptbound/`

Hold the iPhone horizontally.

## Controls

- Left thumb: floating movement joystick
- Right thumb: hold the ATTACK button
- Desktop testing: WASD or arrow keys; Space attacks

## Current prototype

- One player-controlled hero
- Three AI companions: Guardian, Ranger, and Arcanist
- Enemy generators and continuously spawning enemies
- Melee and ranged combat
- Health, food pickups, score, collisions, and scrolling camera
- Installable web-app manifest with landscape orientation

## Development

The playable build is intentionally dependency-free and runs directly in the browser using HTML5 Canvas and JavaScript. Java server features can be added later for accounts, cloud saves, leaderboards, and multiplayer.
